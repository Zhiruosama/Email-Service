# ADR-0003：通用核心与业务适配协议分离

- 状态：Proposed
- 日期：2026-07-28

## 决策

核心协议和领域模型使用中立的 `mailservice` 命名。AI-Nexus 的验证码强类型协议作为
边缘适配器存在，将业务字段映射为版本化模板和通用投递命令。

## 原因

- Mail Service 要服务多个项目；
- 验证码是业务概念，不是邮件投递核心概念；
- 强类型业务适配器可以保留安全性；
- 通用核心可以支持订单、账户通知等新模板，而不修改状态机。

## 后果

- 需要维护通用 Proto 和 AI-Nexus 适配 Proto；
- 两种协议必须共享同一 Application Service；
- 禁止适配器绕过租户、模板、幂等和配额规则；
- 当前 `ainexus.mail.v1` 规范需要同步调整或明确为兼容层。
